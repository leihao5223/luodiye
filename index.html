4 个核心步骤 4 core steps

无论使用 Android 还是 iPhone，主路径都围绕下面 4 个动作展开，只是文案和按钮位置会因语言版本略有不同。 Whether on Android or iPhone, the main flow follows the same 4 actions, with only minor wording differences between language variants.

1

打开 Linked devices / 已关联设备 Open Linked devices

从菜单或设置中进入已关联设备页面，这是所有版本的第一步。 Enter the Linked devices screen from the menu or settings. This is the first step in every variant.

2

点击关联设备 / Link device Tap Link device

在设备管理页面点击主按钮，准备开始新的关联流程。 Tap the main button on the device-management screen to start a new linking flow.

3

改用电话号码关联 Switch to phone-number linking

进入扫描二维码页面后，使用底部的 “Link with phone number instead / 改用电话号码关联”。 Once you reach the QR scanner screen, use the bottom action labeled “Link with phone number instead”.

4

输入验证码 Enter the verification code

最后在设备端看到验证码输入界面，按照应用内提示完成链接。 Finally, enter the verification code shown in the app and complete the link from the official flow.
